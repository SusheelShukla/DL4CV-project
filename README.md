# Layered Representations from a Single Image
A project on how to generate layered representations from a single image.

## Project Description
A project for the course "Deep Learning for Computer Vision" at the IITM, BS Degree in Data Science and Applications.

## Project Structure

Below is the structure of the project:

```
DL4CV-Project
├── appearance
├── corner_image.jpg
├── DL4CV_LayeredRep1Img.ipynb
├── DL4CV_project_summary.csv
├── figures
│   ├── 01_original.png
│   ├── 02_depth.png
│   ├── 03_albedo.png
│   ├── 04_shading.png
│   ├── 05_reconstruction.png
│   ├── layer_01_couch.png
│   ├── layer_02_chair.png
│   ├── layer_03_bird.png
│   ├── layer_04_tv.png
│   ├── layer_05_chair.png
│   ├── layer_06_dining_table.png
│   ├── layer_07_bottle.png
│   ├── layer_08_dining_table.png
│   ├── layer_09_dining_table.png
│   ├── layer_background.png
│   └── metadata.json
├── image.jpg
├── IMG_5151.JPG
├── Layered Representations from a Single Image.pdf
├── layer_metadata.csv
└── README.md
```
- appearance folder - contains the appearance of the layers.
- corner_image.jpg - the original image used for the project.
- DL4CV_LayeredRep1Img.ipynb - the jupyter notebook used for the project.
- DL4CV_project_summary.csv - contains the summary of the project.
- figures folder - contains the figures used and generated durintg the project by the jupyter notebook.
- image.jpg - other image used for the project for trial purposes only.
- IMG_5151.JPG - other image used for the project for trial purposes only.
- Layered Representations from a Single Image.pdf - contains the project report.
- layer_metadata.csv - contains the metadata of the layers.
- README.md - contains the project description.

## Metadata

The metadata of the layers is contained in the `layer_metadata.csv` file.
